
# Protium Loan Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze loan performance, payment behavior, and customer call activity. The dashboard enables stakeholders to monitor key business metrics, identify payment trends, and gain insights into customer interactions.

## Dashboard Pages

### 1. Loan Overview

* Loan portfolio summary
* Key loan performance indicators (KPIs)
* Distribution of loans across categories
* Overall business performance metrics

### 2. Payment Trends

* Payment collection analysis
* Monthly payment trends
* Payment status monitoring
* Revenue and repayment performance tracking

### 3. Call Analysis

* Customer call activity analysis
* Call volume trends
* Customer engagement metrics
* Support performance monitoring

## Key Features

* Interactive filters and slicers
* Dynamic KPI cards
* Trend analysis visualizations
* Drill-down capabilities
* Business performance reporting
* User-friendly dashboard design

## Business Insights

* Identified payment and collection trends.
* Monitored loan portfolio performance.
* Analyzed customer interaction patterns.
* Tracked operational KPIs to support decision-making.
